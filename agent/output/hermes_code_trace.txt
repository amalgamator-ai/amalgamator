1. ARCHITECTURE OVERVIEW
================================================================================

The feature has two orthogonal subsystems that work together:

  A) IterationBudget — a thread-safe counter that caps the total number of
     LLM API calls per agent turn. Parent agents default to 90 iterations;
     subagents default to 50. Each agent gets an independent budget.

  B) ToolCallGuardrailController — a per-turn state machine that tracks
     tool-call signatures and results. It detects three failure patterns:
       - Exact repeated failures (same tool + same args)
       - Same-tool failures with varying args
       - Idempotent no-progress (read-only tools returning identical results)
     It issues warnings (injected into tool results) or hard stops (blocking
     execution + halting the turn) depending on configuration.

Both subsystems are held as instance attributes on the AIAgent class, wired
during init_agent(), reset at the start of each turn, and enforced inside the
conversation loop and tool executor.

Key design principles:
  - IterationBudget is side-effect free (pure counter)
  - ToolCallGuardrailController is side-effect free (returns decisions)
  - Runtime code (conversation_loop, tool_executor, run_agent) owns all
    side effects: injecting messages, blocking execution, halting turns
  - Warnings are always-on by default; hard stops are opt-in
  - execute_code iterations are refunded (don't eat budget)
  - Compression-restart iterations are refunded

Purpose: Thread-safe per-agent iteration counter with consume/refund semantics.

class IterationBudget:
    """Thread-safe iteration counter for an agent."""

    def __init__(self, max_total: int)
        - max_total: The cap (90 for parent, 50 for subagent by default)
        - _used: int = 0 (consumed count)
        - _lock: threading.Lock() (thread safety)

    def consume(self) -> bool
        - Acquires lock, increments _used if _used < max_total
        - Returns True if allowed, False if budget exhausted
        - Called once per loop iteration in conversation_loop.py

    def refund(self) -> None
        - Acquires lock, decrements _used (floor at 0)
        - Called for execute_code-only iterations (cheap RPC)
        - Called on compression restarts (retry, not new work)
        - Called on Ollama context-limit early exits

    @property used -> int
        - Thread-safe read of _used (acquires lock)

    @property remaining -> int
        - Thread-safe: max(0, max_total - _used)

State Management:
  - Held as agent.iteration_budget on each AIAgent instance
  - Recreated at the start of each turn: IterationBudget(agent.max_iterations)
  - Thread-safe via threading.Lock for concurrent subagent scenarios

Invariants:
  - _used never goes below 0 (floor in refund)
  - _used never exceeds max_total (guard in consume)
  - All reads and writes hold the lock

--- 3.4 Controller ---

class ToolCallGuardrailController:
    def __init__(self, config: ToolCallGuardrailConfig | None = None)

    def reset_for_turn(self) -> None
        - Clears all per-turn state:
          _exact_failure_counts: dict[ToolCallSignature, int]
          _same_tool_failure_counts: dict[str, int]
          _no_progress: dict[ToolCallSignature, tuple[str, int]]
          _halt_decision: ToolGuardrailDecision | None

    def before_call(tool_name, args) -> ToolGuardrailDecision
        - Pre-execution check (only blocks when hard_stop_enabled)
        - Checks exact_failure_block_after threshold
        - Checks idempotent no_progress_block_after threshold
        - Returns "block" decision to prevent execution

    def after_call(tool_name, args, result, *, failed=None) -> ToolGuardrailDecision
        - Post-execution observation
        - If failed is None, auto-classifies via classify_tool_failure()
        - On failure: increments exact + same-tool counters
        - On success: clears exact + same-tool counters for that signature
        - For idempotent tools on success: tracks result hash for no-progress
        - Returns warn/halt decisions based on thresholds

    def _append_guardrail_observation(self, tool_name, function_args, function_result,
                                       *, failed: bool) -> str:
        decision = self._tool_guardrails.after_call(
            tool_name, function_args, function_result, failed=failed,
        )
        if decision.action in {"warn", "halt"}:
            function_result = append_toolguard_guidance(function_result, decision)
        if decision.should_halt:
            self._set_tool_guardrail_halt(decision)
        return function_result

def handle_max_iterations(agent, messages, api_call_count) -> str:
    - Prints "⚠️ Reached maximum iterations" warning
    - Injects a user message: "You've reached the maximum number of
      tool-calling iterations allowed. Please provide a final response
      summarizing what you've found..."
    - Makes ONE final API call with NO tools (forces text response)
    - Sanitizes messages (remove internal fields, repair tool-call pairing)
    - Returns the summary text or an error fallback
