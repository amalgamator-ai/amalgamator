1. CODE PATCH EXPLANATION
================================================================================

The patch implements the "Iteration Budget & Agent Loop Safety" feature,
porting Hermes's 62-line IterationBudget class and its integration points
to OpenClaw's TypeScript codebase. The feature provides configurable
per-agent iteration limits with consume/refund semantics and an optional
forced-summary grace call when the budget is exhausted.

LAYER 1 — Core Module (Step 1):
  - src/agents/iteration-budget.ts [NEW]
    IterationBudget class with consume(), refund(), used, remaining
    semantics. Identical API to Hermes but without threading.Lock
    (unnecessary in Node.js). Also includes resolveIterationBudgetConfig()
    which applies hardcoded defaults (90 parent / 50 subagent / true
    summary) to sparse config objects.

LAYER 2 — Configuration (Steps 2-5):
  - src/config/types.agent-defaults.ts [MODIFIED]
    Added IterationBudgetConfig type with enabled, maxIterations,
    subagentMaxIterations, forceSummaryOnExhaustion fields.
    Added iterationBudget field to AgentDefaultsConfig.
  - src/config/types.agents.ts [MODIFIED]
    Added iterationBudget field to AgentConfig for per-agent overrides.
  - src/config/zod-schema.agent-runtime.ts [MODIFIED]
    Added IterationBudgetConfigSchema (z.object with .strict()).
    Added iterationBudget to AgentEntrySchema.
  - src/config/zod-schema.agent-defaults.ts [MODIFIED]
    Imported IterationBudgetConfigSchema.
    Added iterationBudget to AgentDefaultsSchema.
  - src/agents/agent-scope-config.ts [MODIFIED]
    Added IterationBudgetConfig import.
    Added iterationBudget to ResolvedAgentConfig.
    Added shallow merge logic (matching runRetries pattern).

LAYER 3 — Agent-Core Integration (Step 6):
  - packages/agent-core/src/types.ts [MODIFIED]
    Added onBeforeToolCallingRound callback to AgentLoopConfig interface
    with JSDoc documenting the 1-based round counter and false-return
    semantics.
  - packages/agent-core/src/agent-loop.ts [MODIFIED]
    Added toolCallingRound counter. Calls onBeforeToolCallingRound
    before executeToolCalls when stopReason=toolUse && toolCalls.length>0.
    Returns false → emits turn_end + agent_end and stops.
  - packages/agent-core/src/agent.ts [MODIFIED]
    Added public onBeforeToolCallingRound property.

  - packages/agent-core/src/harness/agent-harness.ts [MODIFIED]

    (NOT via this.agent — harness wraps Session, not Agent).

LAYER 4 — Runner Integration (Steps 7-13):

    Extended error kind union with "budget_exhausted".

    (a) Added imports for resolveAgentConfig, IterationBudget,

        buildBudgetExhaustedResult.
    (b) Budget creation: resolveIterationBudgetConfig from merged agent
        config (with ternary guard for optional params.config — V2 FIX #1).
    (c) Outer loop consumption: iterationBudget.consume() on each
        runLoopIterations increment (skipped during budgetSummaryAttempt).
    (d) budgetExhaustedSummaryInstruction added to promptAdditions.
