ANALYSIS METHODOLOGY
================================================================================

For each of the 48 Kagenti features, we determined its status in OpenShell:
  - MISSING: Feature does not exist at all in OpenShell
  - INADEQUATE: Feature exists but has significant gaps
  - EQUIVALENT: Feature exists and is roughly equivalent
  - SUPERIOR: OpenShell's implementation is better

We then searched NVIDIA/OpenShell GitHub issues for CONCRETE evidence of
community demand (reactions, comments, related issues) for each gap.

Features were scored on 5 dimensions (1-10):
  - Community demand (30% weight): Issue counts, reactions, comments
  - Gap severity (25% weight): MISSING=10, INADEQUATE=5-8
  - Impact (25% weight): How much this improves OpenShell
  - Feasibility (15% weight): Practical to port Python/Go → Rust?
  - Independence (5% weight): Can be ported independently?
