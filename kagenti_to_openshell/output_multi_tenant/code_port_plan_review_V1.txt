1. EXECUTIVE SUMMARY
================================================================================

This plan ports Kagenti's multi-tenant deployment support to OpenShell. The
feature operates at two complementary layers:

  Layer 1 — Per-User Ownership (Rust gateway code changes):
    Within a single gateway instance (shared by a team/tenant), enforce
    per-user isolation via the openshell.ai/owner label. This is the
    core Rust work: owner stamping on create, per-user filtering on list,
    ownership checks on get/delete/exec/watch/ssh, admin bypass,
    anti-spoofing.

  Layer 2 — Gateway-Per-Tenant (Helm/infrastructure changes):
    Each tenant (team/organization) gets a dedicated Kubernetes namespace
    with an isolated gateway stack, namespace-scoped RBAC, per-tenant
    OIDC audience scoping, ResourceQuota, LimitRange, and TLS certs.
    This is primarily Helm chart and deployment tooling work.

Both layers compose: Layer 2 isolates tenants at the Kubernetes boundary,
while Layer 1 isolates users within a tenant at the application layer.

The plan preserves backward compatibility: when OIDC is disabled or
multi-tenancy config is absent, all ownership logic is bypassed
(Anonymous principal => no owner stamping, no filtering).

================================================================================
2. ARCHITECTURAL DECISION
================================================================================

DECISION: Adopt the Kagenti "owner-label" approach for Layer 1 and the
"gateway-per-tenant Helm deployment" approach for Layer 2.

Rationale:

  1. Owner-label approach leverages EXISTING OpenShell infrastructure:
     - labels column in objects table (already present)
     - list_with_selector() API (already implemented in both SQLite and
       Postgres; Postgres uses JSONB @> operator for efficient filtering)
     - ObjectMeta.labels in protobuf (already defined)
     - Identity.subject from OIDC JWT (already extracted)
     - Principal inserted into request extensions by multiplex.rs
       middleware (line 623: req.extensions_mut().insert(principal))
     No schema changes to protobuf messages are needed.

  2. Gateway-per-tenant avoids invasive single-gateway multi-tenant changes:
     - No tenant column needed in the database (each gateway has its own DB)
     - No tenant-aware connection pooling
     - No cross-tenant broadcast filtering on watch bus
     - Tenant isolation enforced by Kubernetes namespace RBAC
     - Clean lifecycle management (deploy/destroy per-tenant independently)

  3. OIDC audience scoping per gateway instance is already supported:
     - OidcConfig.audience is a single configurable value
     - Each gateway instance in its own namespace gets its own audience
     - No code change needed for audience-per-tenant; it's config-per-deploy

  Alternatives considered and rejected:

  A. Single gateway, tenant column in DB:
     Would require invasive schema changes, all queries must carry tenant,
     watch bus must filter by tenant, sandbox index must partition by tenant.
     Much higher complexity for marginal benefit.

  B. Virtual tenants via gateway configuration:
     Would require multi-audience OIDC validation, per-request tenant
     resolution, and query-level tenant partitioning. Breaks the clean
     separation that gateway-per-tenant provides.

  //! Per-user ownership enforcement for multi-tenant deployments.
  //!
  //! When OIDC is enabled, each object (sandbox, provider) is stamped with
  //! `openshell.ai/owner = <identity.subject>` at creation time. List, get,
  //! delete, exec, and watch operations enforce that users can only access
  //! their own objects, unless the caller has the admin role.
  //!
  //! When OIDC is disabled (Anonymous principal), ownership is not enforced.

  use super::identity::Identity;
  use super::principal::Principal;
  use openshell_core::driver_utils::{LABEL_OWNER, LABEL_TENANT};
  use std::collections::HashMap;
  use tonic::Status;
  use tracing::{debug, info};

  /// Reserved label key prefix. Client-supplied labels with this prefix
  /// are stripped at creation time to prevent spoofing.
  const RESERVED_LABEL_PREFIX: &str = "openshell.ai/";

  /// Runtime configuration for ownership enforcement.
  /// Built from config + OIDC settings at handler call time.
  ///
  /// NOTE: This is distinct from config::OwnershipSettings which is the
  /// serializable TOML/Helm config struct.
  #[derive(Debug, Clone)]
  pub struct OwnershipEnforcement {
      /// When true, ownership enforcement is active.
      pub enabled: bool,

      /// Role name that grants admin access (ownership bypass).
      pub admin_role: String,
  }

  impl OwnershipEnforcement {
      /// Create from OIDC config. Returns enabled=false when roles are empty.
      pub fn from_authz(admin_role: &str) -> Self {
          Self {
              enabled: !admin_role.is_empty(),
              admin_role: admin_role.to_string(),
          }
      }

      /// Disabled ownership (for backward compatibility).
      pub fn disabled() -> Self {
          Self {
              enabled: false,
              admin_role: String::new(),
          }
      }
  }

  /// Determine whether ownership enforcement should be applied for
  /// the given principal. Returns `None` when ownership is not applicable
  /// (anonymous, ownership disabled, admin bypass).
  pub fn resolve_owner(
      config: &OwnershipEnforcement,
      principal: &Principal,
  ) -> Option<String> {
      if !config.enabled {
          return None;
      }
      match principal {
          Principal::User(user) => {
              if is_admin(&user.identity, &config.admin_role) {
                  None
              } else {
                  Some(user.identity.subject.clone())
              }
          }
          Principal::Sandbox(_) | Principal::Anonymous => None,
      }
  }

  /// Stamp owner label onto a mutable label map, stripping any
  /// client-supplied openshell.ai/* keys first (anti-spoofing).
  pub fn stamp_owner_labels(
      labels: &mut HashMap<String, String>,
      owner: Option<&str>,
  ) {
      // Strip all client-supplied reserved labels (anti-spoofing).
      labels.retain(|key, _| !key.starts_with(RESERVED_LABEL_PREFIX));

      // Stamp owner if applicable.
      if let Some(owner_id) = owner {
          let sanitized = sanitize_label_value(owner_id);
          labels.insert(LABEL_OWNER.to_string(), sanitized);
          debug!(owner = %owner_id, "stamped owner label on object");
      }
  }

  /// Build a label selector string that includes the owner filter.
  /// Returns `None` when no filtering is needed (admin/anonymous/disabled).
  pub fn owner_label_selector(
      config: &OwnershipEnforcement,
      principal: &Principal,
  ) -> Option<String> {
      let owner = resolve_owner(config, principal)?;
      Some(format!("{}={}", LABEL_OWNER, sanitize_label_value(&owner)))
  }

  /// Combine an optional user-provided label selector with the owner filter.
  pub fn merge_label_selectors(
      user_selector: &str,
      owner_selector: Option<&str>,
  ) -> String {
      match (user_selector.is_empty(), owner_selector) {
          (true, None) => String::new(),
          (true, Some(owner)) => owner.to_string(),
          (false, None) => user_selector.to_string(),
          (false, Some(owner)) => format!("{},{}", user_selector, owner),
      }
  }

  /// Check ownership of an existing object. Returns `Ok(())` if the caller
  /// is the owner or an admin. Returns `Err(Status::not_found)` to avoid
  /// leaking object existence to non-owners.
  ///
  /// `object_labels` is the label map from the protobuf ObjectMeta.
  #[allow(clippy::result_large_err)]
  pub fn enforce_ownership(
      config: &OwnershipEnforcement,
      principal: &Principal,
      object_labels: &HashMap<String, String>,
      object_kind: &str,
  ) -> Result<(), Status> {
      if !config.enabled {
          return Ok(());
      }
      match principal {
          Principal::User(user) => {
              if is_admin(&user.identity, &config.admin_role) {
                  return Ok(());
              }
              let caller_subject = &user.identity.subject;
              if let Some(owner) = object_labels.get(LABEL_OWNER) {
                  if owner == caller_subject {
                      Ok(())
                  } else {
                      info!(
                          caller = %caller_subject,
                          owner = %owner,
                          kind = %object_kind,
                          "ownership check failed: caller is not owner"
                      );
                      Err(Status::not_found(format!("{object_kind} not found")))
                  }
              } else {
                  // Object has no owner label (admin-created / legacy).
                  // Non-admin users can access shared objects.
                  Ok(())
              }
          }
          Principal::Sandbox(_) | Principal::Anonymous => Ok(()),
      }
  }

  /// Returns `true` if the identity has the admin role.
  fn is_admin(identity: &Identity, admin_role: &str) -> bool {
      !admin_role.is_empty() && identity.roles.iter().any(|r| r == admin_role)
  }

  /// Sanitize a string for use as a Kubernetes label value.
  ///
  /// Kubernetes label values must be <= 63 chars and match:
  ///   ([A-Za-z0-9][-A-Za-z0-9_.]*)?[A-Za-z0-9]
  ///
  /// REVIEW FIX: Also trims leading/trailing non-alphanumeric chars to
  /// ensure the value starts and ends with alphanumeric as K8s requires.
  pub fn sanitize_label_value(value: &str) -> String {
      let sanitized: String = value
          .chars()
          .filter(|c| c.is_ascii_alphanumeric() || *c == '-' || *c == '_' || *c == '.')
          .take(63)
          .collect();
      // Trim leading/trailing non-alphanumeric chars (K8s requirement).
      let trimmed = sanitized
          .trim_start_matches(|c: char| !c.is_ascii_alphanumeric())
          .trim_end_matches(|c: char| !c.is_ascii_alphanumeric());
      if trimmed.is_empty() {
          "unknown".to_string()
      } else {
          trimmed.to_string()
      }
  }

  /// Extract the Principal from a tonic Request, returning Anonymous
  /// if not present (backward compatibility for unauthenticated paths).
  pub fn extract_principal<T>(request: &tonic::Request<T>) -> Principal {
      request
          .extensions()
          .get::<Principal>()
          .cloned()
          .unwrap_or(Principal::Anonymous)
  }

  pub(super) async fn handle_get_sandbox(
      state: &Arc<ServerState>,
      request: Request<GetSandboxRequest>,
  ) -> Result<Response<SandboxResponse>, Status> {
      let principal = ownership::extract_principal(&request);
      let name = request.into_inner().name;
      if name.is_empty() {
          return Err(Status::invalid_argument("name is required"));
      }

      let sandbox = state.store
          .get_message_by_name::<Sandbox>(&name)
          .await
          .map_err(|e| Status::internal(format!("fetch sandbox failed: {e}")))?
          .ok_or_else(|| Status::not_found("sandbox not found"))?;

      // Enforce ownership: non-owners get NotFound.
      let sandbox_labels = sandbox.metadata.as_ref()
          .map(|m| &m.labels)
          .cloned()
          .unwrap_or_default();
      let ownership_config = state.ownership_config();
      ownership::enforce_ownership(
          &ownership_config, &principal, &sandbox_labels, "sandbox"
      )?;

      Ok(Response::new(SandboxResponse { sandbox: Some(sandbox) }))
  }

          ownership::enforce_ownership(

          )?;

      Ok(Response::new(DeleteSandboxResponse { deleted }))
  }

         limit: u32,

     ) -> Result<Vec<Provider>, Status> {

             let visible: Vec<Provider> = all_providers.into_iter()
                 .filter(|p| {
                     let labels = p.metadata.as_ref()

         }
