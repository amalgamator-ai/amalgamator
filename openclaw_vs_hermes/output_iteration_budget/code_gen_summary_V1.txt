1. EXPLANATION OF CODE PATCH
================================================================================

This patch ports the "Iteration Budget & Agent Loop Safety" feature from
Hermes Agent (Python) to OpenClaw (TypeScript). The feature provides a
per-agent iteration counter with consume/refund semantics that prevents
runaway agent loops by enforcing configurable limits on the number of LLM
iterations per run.

The implementation follows the code_port_plan_review_V3.txt exactly,
implementing Steps 1-16 (omitting the full integration test suite for
run.ts due to its reliance on the 755-line mock harness infrastructure).


CORE MODULE (Step 1):
  - IterationBudget class with consume(), refund(), used, remaining
  - resolveIterationBudgetConfig() for applying hardcoded defaults
  - Idiomatic TypeScript (no threading.Lock needed in single-threaded Node.js)

CONFIGURATION (Steps 2-5):
  - IterationBudgetConfig type in types.agent-defaults.ts
  - Zod schema validation (IterationBudgetConfigSchema) with strict mode
  - Shallow merge in resolveAgentConfig (same pattern as runRetries)
  - Per-field default resolution function (Layer 2 consumption-site pattern)

AGENT-CORE INTEGRATION (Step 6):
  - onBeforeToolCallingRound callback added to AgentLoopConfig interface
  - Called in agent-loop.ts inner loop before executeToolCalls dispatch
  - 1-based round counter incremented on each tool-calling round
  - Returning false stops tool execution and emits agent_end
  - Mapped in both Agent.createLoopConfig and CoreAgentHarness.createLoopConfig

RUNNER INTEGRATION (Steps 7-13):
  - onBeforeToolCallingRound added to EmbeddedRunAttemptParams
  - Budget created from resolved config in run.ts initialization
  - Budget consumption via onBeforeToolCallingRound callback
  - Budget exhaustion detection with guards matching compaction continuation:
    * !emptyAssistantReplyIsSilent (FIX #3)
    * !timedOut (FIX #2)
    * !attempt.yieldDetected (FIX #3)
    * Stale retry instruction cleanup (FIX #4)
  - Forced summary flow: refund 1, inject summary instruction, continue
  - Summary attempt completion handling with result builder
  - "budget_exhausted" added to error kind union
  - Budget-exhaustion result builder in budget-exhaustion.ts
  - Callback wired through attempt.ts -> activeSession.agent

ERROR KIND (Step 9):
  - "budget_exhausted" added to EmbeddedAgentRunMeta.error.kind union
