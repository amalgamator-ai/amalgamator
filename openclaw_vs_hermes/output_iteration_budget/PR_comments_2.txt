### Reviewer Comments Addressed

#### 1. [P1] Honor subagent iteration caps

> **Original comment:** `subagentMaxIterations` is accepted and defaulted, but the runtime always constructs the budget with `maxIterations`. A configured subagent cap is therefore silently ignored for subagent sessions; select the subagent cap for subagent session keys or remove the field until supported.
> *(Confidence: 0.89 | File: `src/agents/embedded-agent-runner/run.ts:1591`)*

**Fix:** Added subagent detection using `params.spawnedBy` and conditional cap selection. When `spawnedBy` is set (subagent run), the `IterationBudget` is now constructed with `resolvedBudgetConfig.subagentMaxIterations` (default: 50) instead of `maxIterations` (default: 90). This correctly honors per-session-type caps as designed.

---

#### 2. [P1] Count each budgeted tool round once

> **Original comment:** The same `IterationBudget` is consumed before each outer attempt and again by `onBeforeToolCallingRound`. This makes the configured limit smaller than advertised, and low values can block the first tool round before it executes; keep one canonical counter or split the counters into separate named budgets.
> *(Confidence: 0.87 | File: `src/agents/embedded-agent-runner/run.ts:1945`)*

**Fix:** Removed the redundant outer-loop `iterationBudget.consume()` call (4 lines). The `onBeforeToolCallingRound` callback is now the sole budget consumption point, counting exactly once per LLM tool-calling round. Non-productive iterations (compaction retries, auth retries, timeout retries) are correctly excluded from consumption since they have their own independent limits.

---

#### 3. [P2] Document the new config surface

> **Original comment:** This strict `iterationBudget` block is added to the runtime schema without matching config help, labels, or gateway docs. Users and UI/help surfaces will not discover or understand the new keys, and config-contract policy expects schema, metadata, and docs to move together.
> *(Confidence: 0.82 | File: `src/config/zod-schema.agent-runtime.ts:77-84`)*

**Fix:** Added 10 `FIELD_HELP` entries and 10 matching `FIELD_LABELS` entries covering all `iterationBudget` keys for both `agents.defaults` and `agents.list[]` scopes. Help text describes defaults, behavior, and when each field takes effect. Follows the established pattern used by the adjacent `runRetries` config block.
