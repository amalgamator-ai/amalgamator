1. WHAT WAS IMPLEMENTED
================================================================================

This iteration implements the "Iteration Budget & Agent Loop Safety" feature,
porting Hermes's IterationBudget class (agent/iteration_budget.py) to OpenClaw's
TypeScript codebase. The implementation was done from scratch but incorporates
all learnings and fixes identified in the V1 and V1-REVIEW iterations.

CORE MODULE (Step 1 & 5):
  - IterationBudget class with consume/refund/used/remaining semantics
  - resolveIterationBudgetConfig() for Layer 2 default resolution
  - Defaults: 90 iterations (parent), 50 (subagent), forceSummary=true

CONFIGURATION (Steps 2-4):
  - IterationBudgetConfig type in types.agent-defaults.ts
  - IterationBudgetConfigSchema Zod validation (without baked-in .optional())
  - Per-agent iterationBudget in types.agents.ts and AgentEntrySchema
  - Shallow merge in resolveAgentConfig (matching runRetries pattern)
  - Field added to AgentDefaultsSchema with .optional() at usage site

AGENT-CORE INTEGRATION (Step 6):
  - onBeforeToolCallingRound callback in AgentLoopConfig interface
  - toolCallingRound counter in runLoop() (1-based, outside outer while)
  - Callback invocation before executeToolCalls with false-return cleanup
  - Mapped in Agent.createLoopConfig and CoreAgentHarness.createLoopConfig
  - Public property on both Agent and CoreAgentHarness classes

RUNNER INTEGRATION (Steps 7-13):
  - onBeforeToolCallingRound in EmbeddedRunAttemptParams
  - Wired in attempt.ts via activeSession.agent.onBeforeToolCallingRound
  - Budget initialization in run.ts (after runLoopIterations declaration)
  - Outer-loop consumption: iterationBudget.consume() on each iteration
  - Inner-loop consumption: onBeforeToolCallingRound callback
  - budgetExhaustedSummaryInstruction added to promptAdditions array
  - Budget exhaustion detection with full guard set:
    !emptyAssistantReplyIsSilent, !timedOut, !attempt.yieldDetected,
    !aborted, !promptError, !attempt.clientToolCalls, !budgetSummaryAttempt
  - forceSummaryOnExhaustion flow with refund + summary attempt
  - Stale instruction cleanup on budget exhaustion
  - "budget_exhausted" error kind in EmbeddedAgentRunMeta
  - buildBudgetExhaustedResult() helper
  - BUDGET_EXHAUSTION_SUMMARY_INSTRUCTION constant
