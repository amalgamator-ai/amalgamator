### Reviewer Comments Addressed

#### 1. [P1] Do not refund the budget before the forced summary turn

> *"When `forceSummaryOnExhaustion` is enabled, the refund makes the next summary attempt pass `onBeforeToolCallingRound` if the model ignores the no-tool instruction, so it can execute another tool batch after the configured budget is exhausted."*
> — `src/agents/embedded-agent-runner/run.ts:3896` (confidence: 0.89)

**Fix:** Removed the `iterationBudget.refund()` call on the forced-summary path. The budget now stays at zero after exhaustion. If the model ignores the no-tool instruction and requests tools during the summary turn, `onBeforeToolCallingRound` calls `consume()` which returns `false`, and `agent-loop.ts` stops cleanly without executing any tools. This makes the budget a hard cap that cannot be bypassed. A 5-line explanatory comment replaces the removed line.

Two focused regression tests were added:
- **"blocks tools during forced summary when no refund is given"** — proves `consume()` returns `false` after full exhaustion, confirming fail-closed behavior.
- **"a refund before summary would incorrectly allow tool execution"** — documents the anti-pattern that was fixed, showing `refund()` + `consume()` would incorrectly return `true`.

#### 2. [P2] Document the public iterationBudget config keys

> *"The PR adds strict `openclaw.json` keys, but the public config docs still document adjacent `runRetries` without any `iterationBudget` section for scope, defaults, precedence, or exhaustion behavior."*
> — `src/config/zod-schema.agent-runtime.ts:77-84` (confidence: 0.84)

**Fix:** Added a full `### agents.defaults.iterationBudget` section (41 lines) to the public config docs at `docs/gateway/config-agents.md`, placed between the existing `runRetries` and `contextPruning` sections. The documentation includes:
- Feature description and opt-in callout
- JSON5 config example with both `agents.defaults` and `agents.list[]` per-agent override
- All 4 config fields documented with accurate defaults (`enabled: false`, `maxIterations: 90`, `subagentMaxIterations: 50`, `forceSummaryOnExhaustion: true`)
- Scope and precedence rules
- Exhaustion behavior (3 cases: summary turn with tool-blocking, immediate error, metadata output)
- Iteration counting semantics (only LLM tool-calling rounds count; non-productive retries excluded)
